AUD00 Backup Chromebook

This is a personal, single-user backup workflow using rclone to access selected Google Drive files and create local backup copies on storage controlled by the account holder.

Purpose

The utility is intended to request read-only Google Drive access to download or export files selected by the account holder. It does not offer a public sign-in service.

Data use

Files are backed up to local or removable storage chosen by the account holder. OAuth authorization is handled in the local rclone configuration; tokens and backup content are not published here. This informational website neither requests OAuth credentials nor receives Drive file contents.

For details, read the Privacy Policy.
